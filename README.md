# 🎮 Mibel FF Bot - بوت إدارة حسابات فري فاير

بوت تيليجرام متكامل لإدارة حسابات Free Fire، يوفر مجموعة واسعة من الخدمات مثل كشف الاستعادة، كشف الروابط الثانوية، تغيير بريد الاستعادة، حرق التوكن، زيادة الزيارات، تغيير الاسم، إدارة القبائل، طلبات الصداقة، فحص الحظر، وعرض أحداث اللعبة.

---

## ✨ الميزات

### 🔐 خدمات الحساب الأساسية
- **كشف الاستعادة**: عرض البريد الإلكتروني المرتبط بالحساب وحالة طلبات التغيير.
- **كشف روابط**: عرض جميع المنصات المرتبطة (فيسبوك، جوجل، آبل، تويتر، هواوي، VK).
- **تجربة رمز الأمان**: التحقق من صحة رموز OTP.
- **إضافة/تغيير استعادة**: تغيير بريد الاستعادة بخطوات آمنة (OTP + كلمة مرور ثانوية).
- **حذف روابط ثانوية**: إلغاء طلبات الربط المعلقة.
- **حرق التوكيل**: تسجيل الخروج الإجباري من جميع الأجهزة.

### 🆕 خدمات متقدمة
- **زيادة زيارات الحساب**: جلب معلومات الحساب (الاسم، المستوى، الإعجابات، المنطقة).
- **تغيير الاسم**: تغيير اسم المستخدم في اللعبة.
- **إدارة القبيلة**: الانضمام أو مغادرة القبائل بسهولة.
- **طلب صداقة**: إرسال طلبات صداقة لحسابات أخرى.
- **فحص الحظر**: التحقق من حالة الحظر.
- **أحداث اللعبة**: عرض الأحداث الحالية في Free Fire.
- **قائمة الرغبات**: عرض قائمة الرغبات الخاصة بالحساب.

### 👑 نظام الاشتراكات
- **باقات متعددة**: شهر، 3 أشهر، مدى الحياة.
- **نظام النقاط**: مكافآت لكل تفعيل.
- **أكواد تفعيل**: توليد واستخدام أكواد للاشتراكات.
- **لوحة تحكم الأدمن**: إدارة المستخدمين والأكواد.
